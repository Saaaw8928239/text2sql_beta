## О проекте

**Text2SQL HR** — это интеллектуальная система, позволяющая сотрудникам отдела кадров задавать вопросы к базе данных **на обычном русском языке**, а не на SQL.

Система автоматически:
- Понимает запрос на естественном языке
- Генерирует корректный SQL-запрос
- Выполняет его в PostgreSQL
- Возвращает результат в удобном виде

---

## Основные возможности

- **Полностью на русском языке** — запросы формулируются естественно
- **Мощная LLM** — Qwen2.5-3B-Instruct (4-битная квантованная версия)
- **Высокая точность** — **92%** на тестовом наборе из 100 запросов
- **Безопасность** — двухуровневая защита (NL + SQL), только режим чтения
- **Удобный веб-интерфейс** — три панели (история, запрос, SQL + результат)
- **Экспорт данных** — CSV и PDF
- **Кэширование** запросов для ускорения
- **Полная локализация** — данные не уходят в облако

---

## Технологический стек

- **Backend**: Python + Flask
- **LLM**: Qwen/Qwen2.5-3B-Instruct (BitsAndBytes 4-bit)
- **База данных**: PostgreSQL
- **Frontend**: HTML + CSS + JavaScript (без тяжёлых фреймворков)
- **Машинное обучение**: Transformers + PyTorch
- **Экспорт**: FPDF (PDF), встроенный CSV

## Запуск

### 1. Клонирование репозитория

```
git clone https://github.com/Saaaw8928239/text2sql_beta.git
cd text2sql_beta
```

### 2. Создание и активация виртуального окружения

```
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/Mac:
# source venv/bin/activate
```

### 3. Установка зависимостей

```
pip install -r requirements.txt
```

### 4. Настройка базы данных

Создайте базу company_db
Выполните скрипты:

```
psql -U postgres -d company_db -f create_db.sql
psql -U postgres -d company_db -f insert_test_data.sql
```

### 5. Настройка переменных окружения

Создайте файл .env:

```
DB_HOST=localhost
DB_PORT=5432
DB_NAME=company_db
DB_USER=postgres
DB_PASSWORD=твой_пароль

SECRET_KEY=super-secret-key-2026
```

### 6. Запуск

```
python app.py
Перейдите в браузере: http://localhost:5000
```
